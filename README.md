- Cinematic Three.js data universe with animated nodes and processing core
- Interactive 3D profile identity object
- Color-changing custom cursor with text-hover feedback
- Interactive project showcase with live-system themes
- Responsive Journey timeline with active milestones
- Structured project and profile data in `src/data/portfolio.ts`
- Reduced-motion and mobile support
